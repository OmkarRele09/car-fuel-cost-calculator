# 🚗 Fuel Cost Calculator in C

A simple beginner-friendly C program that calculates fuel consumption and total fuel cost for a trip based on the distance travelled, vehicle mileage, and petrol price.

This is one of my first mini projects while learning C programming.

## 📌 Features

- Takes distance travelled as input
- Takes vehicle mileage as input
- Takes petrol price per litre as input
- Calculates fuel consumed
- Calculates total fuel cost
- Displays the trip results
